⑤ 使用纪律（如果采纳，写进 CLAUDE.md）

  • 全产品只此一种光泽：金属虹光只出现在 分数徽章 / send 生成态 / Gallery featured / landing hero，新落点需评审。
  • 配方锁定：结构是金属（明度大幅振荡 + 镜面扫光，这是和"整条色带"的分界线），色彩在金属结构内流动（chroma ≤ 0.07）；亮色主题金属压暗、暗色提亮，两态必须都验收。
  • 日常界面零彩色：按钮、导航、徽章、focus ring 维持冷灰单色，不引入第二个彩色。
  • 动效礼仪：流转周期 ≥ 8s（send 扫光除外），prefers-reduced-motion 下全部静止。
  • 描边纪律不变：金属边缘用 padding-box / border-box 双层背景实现，不算违反「卡片无 border」约定。
  • 扁平分层：bg → card → block 只用明度阶梯分层，禁投影 / 纵向渐变 / 内高光（拟物手法）；级差 0.03~0.09 内选，块凸（亮）凹（暗）只能选一个方向全局统一。
  • 氛围光只在 landing：白欧泊 radial glow（blur ≥ 24px，不挡交互）仅用于 hero 背后，产品界面内不铺。
