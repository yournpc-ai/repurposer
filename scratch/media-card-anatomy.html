按 node type 规划 — 两种媒体节点,两种解剖

之前的误诊:把「素材卡」和「成片剪辑卡」当成一个类型,给了同一套 24px muted chips 词汇——结果阅读型不像阅读器,编辑结构型不像时间轴。 本原型按 type 分开修:素材卡 = 舞台 + 转写稿阅读器;成片剪辑卡 = 舞台 + NLE 检视时间轴(Final Cut / Premiere 语法:ruler、道高、clip 块、左道头、同轴播放头;按 L3 铁律只借检视、不借编排——拖柄/加轨/音量杆/转场永不进)。

左边:阅读型没有阅读器的样子;右边:编辑结构型没有时间轴的样子——track 在哪?

素材卡 · 阅读型 ASSET — 舞台 + 转写稿阅读器

① 一体边框:画面+转写稿同入一环(发丝线基座),不再是三个游离对象;② 舞台高度钉死 aspect:400×225 整幅 16:9,不再被 transcript 挤压截断;③ cue 区单向纵向滚动(overflow-x 裁掉),时间 chip 上浮现、永不遮字;④ 阅读区加高到 5-6 行,进度皮贴舞台下缘。 零翻案factsbar 外置律保留

成片剪辑卡 · 编辑结构型 CLIP — 舞台 + NLE 检视时间轴

借五条 NLE 语法:ruler(0:00–0:45 同一把尺)、道高(视频道 34px)、clip 是物体(圆角填充块,块签服务端预格式化)、左道头 gutter(🎬/💬/🎵/🎙)、跨道播放头。字幕道连续带零内嵌文字,句文本在 hover。score/质检从画面撤下,并入 ruler 右端。 右案 360 宽把 9:16 舞台信箱化——比例贴近参考图,时间轴才有施展宽度。 L3:只检视不编排360 宽需改服务端 frame 取景ruler 刻度标签需服务端预格式化或拍板豁免

终态同帧 两型各自成立,远看即分

阅读型 = 稿为主;编辑结构型 = 轴为主。画布上不再需要读字就能分清谁是原料、谁是作品。
