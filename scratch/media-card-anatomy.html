hover / 卡面 / 点击 — 不是三选一,是按信息秩分层

行业取证(下方§证据)后的结论:结构层常驻卡面,补充读数 hover,深详情点击。 纯舞台 + hover 揭示三面受敌:NN/g 证明隐藏使发现性近腰斩、触屏无 hover 手势、全行业零主流先例。 布局同时收敛:Image #4 揭示轨道 = 连线接口(每道左缘 port 按道高落位),右挂会斩断连线语义—— 所以所有比例一律下挂,竖屏的轨道安放在下方(Descript/Premiere/CapCut 的底部停靠惯例)。

hover = 读数 · 点击块 = seek · 点击卡面空白 = L2 检视面板

证据 三路调研 · 2026-10

可用性研究 hover 的合法边界

  • NN/g Tooltip 指南:hover 是瞬态元素,Don't use tooltips for information that's essential to task completion——必需信息必须常驻。nngroup.com
  • NN/g 隐藏导航实验(179 人):隐藏主导航 → 使用率 27% vs 48%,任务慢 39%。「隐藏 = 发现性腰斩」是最广引用的定量证据。nngroup.com
  • NN/g 渐进披露:可行但两硬标准——主次切分正确 + 进入下一层的路径显而易见;the very fact that something appears on the initial display tells users that it's important。nngroup.com
  • Shneiderman(1996,9000+ 引用):overview first, zoom and filter, then details on demand——概览常驻、细节按需(未规定 hover 还是 click)。
  • Figma Dev Mode 教科书:hover = 瞬态读数(移开即逝),click = 持久 inspect 面板——「hover 给 glance,click 给 study」的双层模板。help.figma.com
  • 触屏:Apple HIG 用 long-press context menu 等价 hover,但发现性同样差;更稳的是选中即展开 inspector(与 Figma click 层同构)。
  • 反面:Miro 悬浮 toolbar 遮内容遭官方论坛投诉要求可移/可藏;ComfyUI Nodes 2.0 反弹针对的是渲染质量而非「参数常驻」本身。

视频工具惯例 transcript 与 tracks 的座位

  • 全行业无主流工具用 hover 揭示时间轴或转写稿(定向搜索零命中)。悬浮形态唯一先例 = Clipchamp 的选中触发浮动 toolbar。
  • 受限面积的行业答案 = 折叠 + 点击展开,不是 hover:Descript 2025 大改版时间轴默认完全折叠(点底栏箭头展开);Clipchamp 可折叠;CapCut 移动版点按片段 → 底部抽屉。vidpromom.com
  • transcript 停靠惯例 = 左/侧面板:Premiere Text 面板(Captions workspace 停靠左)、Resolve 20 转写稿住 Source viewer Transcript Tab、Riverside 三面板(转写稿左/预览右上/时间轴底部)。rippletraining.com
  • tracks 停靠惯例 = 底部:CapCut / Veed / Clipchamp / Kapwing / Descript 全部底部时间轴;Resolve 20 新增竖屏自适应布局仍底部。
  • 反例教材:FCP 11 无完整转写稿视图被评测点名批评;Wisecut 极端案没有时间轴(转写稿即 storyboard),缺点正是「没有轴可修 AI 的坏剪」。larryjordan.com
  • Descript 杀手特性 = 删字即剪(省 50-70% 时间)——transcript 是阅读+编辑主界面,常驻是它的价值本身。

画布节点产品 LibTV / FLORA / ComfyUI / MiniMax

  • 主流收敛:卡面只放预览+名称,参数进双击/侧栏——LibTV(双击→参数、选中→顶部工具栏、右侧栏调模型)、FLORA、Runway Workflows(2025-10)、Krea Nodes(2026-03)一致。ComfyUI 式全参数常驻被公认密度过高(Nodes 2.0 反弹)。smzdm.com
  • hover 的先例 = 读数层:FLORA / MiniMax Design 的 hover 提示词框——hover 只装提示词读数,不装结构。(用户实地截图举证)
  • L2 的行业形态 = 点击开 modal 编辑器:MiniMax「AI剪辑工坊」点卡 → 全屏 modal(播放器+底部时间轴+右 agent 面板);LibTV 连 ≥2 视频节点调出「视频合成」外置时间轴面板。(用户实地截图举证)
  • 逐轨 port 无公开先例:LibTV/FLORA/Runway/Krea 均为节点级 typed port;参考图(Image #4)的「每道左缘独立 port」属少见设计——采用需自证连线可读性,但截图实物本身就是可读性证据。varoo.cn
  • 密度警示:FLORA 4.8/5 高分但「学习曲线陡」居评测首槽点;Morphic 把「无节点无连线」当卖点——节点工具的信息密度是公认市场痛点。morphic.com
