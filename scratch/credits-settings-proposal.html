C 确认 pill 的仅剩两种触发
这个方向看起来对吗？ 开始
触发一：用户在设置里把任一档拨到「询问」。执行=询问 → Start 不带价；费用=询问 → Start 带价（下行）。
这个方向看起来对吗？ 开始· 约 420 积分
费用=询问档：Start 携带预估价，一次点击 = 知情同意。
这套方案无法提前估价，要先做一版看看吗？ 开始· 估价随运行确定
触发二（内部守卫线，任何设置下生效）：方案 fold 超过守卫上限，或含 NULL 不可报价节点——无法报价本身就是最需要披露的事实。
  • 默认（auto+auto）下此 pill 永不出现——方案呈现即开工。pill 从默认路径退役，只在用户主动要闸或系统守卫时登场。
  • 服务端强制点不变：evaluate_start_gate 读两档设置 + 守卫线，前端按钮从不是唯一防线。
