## 二、目前已有的功能

**1. 素材摄入** — 视频 / 音频 / 照片 / 幻灯片（PPT·PDF 转图）/ 文字稿皆可进；语音转写精确到每个词；AI 自动理解素材（高潮点 / 金句 / 话题边界 / 人脸位置），理解结果复用不重复花钱。

**2. 内容生成（8 张配方卡全部点亮）** — 每张卡 = 一道"招牌菜"，点卡即做：

| 族 | 卡 | 说明 |
|---|---|---|
| 视频 | 高光短片 | 长视频自动选段出竖屏 clips，带推荐分与理由 |
| 视频 | 演讲短片 | 人脸动态追踪，大型登台中景自动切竖屏 |
| 视频 | 访谈分镜 | 自动识别"谁在说话"并切换画面（检出率 99%+，归属准确率 95%+） |
| 视频 | 多语言字幕 | 单语 / 双语对照字幕，任意语言组合 |
| 视频 | 图文视频 | 照片·幻灯片 + 文字稿出片（Ken Burns 运镜） |
| 音频 | 原声 AI 配音 | 声纹克隆多语言配音，音画对齐 |
| 文本 | 社媒帖 / 金句卡 / 轮播 | 按用户风格写作，金句卡为 9:16 叠卡视频 |

**3. 精修** — 自然语言驱动一切（"把第 2 条翻译成法语"）；手动剪辑器（删文字 = 剪视频）；**每次修改留痕可撤销**（人和 AI 同一套操作模型）；**质量环**：生成 → 自动检查 → 打回 / 回退 / 升级，末轮不再天然等于最优轮。

**4. 记忆 / 人设** — AI 学习用户的写作风格、口吻、声纹、皮肤（字体 / 颜色 / 字幕样式）；产物带可辨认的个人印记，对抗"通用 AI 腔"（LinkedIn 对通用 AI 腔约 94% 检测率并降触达）。

**5. 发布** — LinkedIn / TikTok 一键直发**代码完成**，待平台开发者权限审批后开放联调；发布结果进通知中心。

**6. 平台工程** — 全栈容器化并已部署生产环境；中英双语界面；明暗双主题；断线恢复；每步生成成本逐笔记账；安全登录（邮箱验证码）。
