# 视频剪辑师产品要求

Repurposer 是通过自然语言操作持久视频工程的专业 AI 视频剪辑师。用户把素材和目标交给 Agent，在同一个 Chat 里看片、指认一处修改、比较版本并接收成片。Agent 能理解普通效果描述和半专业术语，依据用户素材决定如何实现。画中画、动画和蒙版优先从轨道、对象属性和时间变化组合。专业方向与已验证能力分别记录。

用户可以直接要求局部调整，约束和未点名的内容在版本间保留。信息足够时自主行动，目标或授权存在实质歧义时询问。复杂构思按需用文字与真实素材说明。新增付费制作和重大内容变化须有许可。

每次预览指明版本和范围。正式交付绑定具体 Output，允许用户回看、下载及基于当前工程继续编辑。验收分别核对成片、Agent 的观察与陈述、交付与恢复。指标包括首次跨素材成功、连续修订保持率、失败后是否重复编辑或扣费，以及包含失败尝试的总成本。

作品与工具的主合同见 [Agent Editor](tasks/new-agent.md)，本阶段能力及真实证据见 [I8](tasks/i8.md)，发布边界见 [进度](PROGRESS.md)。
