# 视频编辑与局部预览

文字动画由 Agent 直接用原生文字、预设与动画制作。新建和局部修改分别由 create_video 和具体编辑工具写入版本。

> Status: Chat 修订现行，精确编辑验收开放（2026-11-16）。作品模型见 [VIDEO_PROJECT](VIDEO_PROJECT.md)，渲染见 [RENDERING](RENDERING.md)，实施与剩余验收见 [统一视频合同](tasks/i8.md)。

## 1. 编辑入口

在同一 Chat 指认作品、版本、目标对象或时间范围。用户有明确引用时服务端必须钉该目标；定位有实质歧义时先问。修订基于当前版本，检查 owner、来源权限、时间窗、对象与 base_ref，通过唯一内容写口保存新的不可变 CompositionVersion。旧消息与交付继续打开原来钉定的版本；过期编辑请求保留冲突语义。

原生文字、字幕、声音和视觉对象可以独立修改。播放源码必须可流式读取和寻址；字幕与口播选段依赖真实 ASR 词级时间。用户手工独立修改的字幕在派生更新时保留。inspect_clip 显示目标片段整对象的缩放和位移点，set_keyframe 可修改其中一个已有值。在 OxValue 隔离副本，Agent 根据用户原句定位右侧估值卡标题，查看修改前后同一时间窗并交付 v17。270 帧实测保留推近、标题及左侧主文案。已有缩放或位移点以外的增删、移时、改 easing、蒙版与跟踪均超出该次验收。[旅程与画面](tasks/agent-editor-evidence/iteration-7/README.md)

## 2. 分镜、Scrub 与 Inspector

分镜按需呈现。显式动态检查按确切版本、digest 与目标窗口读取局部 spec。最小 Inspector 使用明确的 Text Clip 和 TextObject 调整字号。拖动、试听和 seek 使用本地草稿，Apply 才提交带 base_ref 的直接 Op 批；相关修改一批原子落一个新版本。Output 的 region mention 提供帧时间、源像素和归一化选区，服务端据此投影当前候选目标；选区本身不证明内部对象可编辑。保留取消、失败回滚、键盘操作与刷新恢复。

编辑能力保持有界。自由多轨时间线、自由层合成、自由转场编辑、stock B-roll 库、通用人脸或物体追踪和离线客户端渲染仍在产品范围之外。现行交付按视频卡的下载能力提供。

## 3. 验收

- 在真实上传视频中用 ASR 词轴定位，核对自然语言选段、原生字幕和字幕手改保护。对明确引用、歧义和模型与用户目标不一致的情况检查服务端钉版及零误写。
- 局部属性编辑应只改目标，覆盖预览、取消、Apply、409、键盘操作与刷新。比较同一版本的预览和成片实际帧及音频。
- 修订保存不触发制作或扣费。制作需要现有授权，交付读取该消息钉定的视频。精确编辑扩展和完整视听验收由当前视频合同跟踪。
