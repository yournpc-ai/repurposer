# Chat 中的剪辑旅程

| 用户意图 | Agent 与 Chat | 可复核结果 |
|---|---|---|
| 提供素材，请剪一版 | 读取来源，使用原生工具保存初稿。构思可用正文与媒体表达 | 固定素材、初版身份、可播放范围 |
| 指定镜头修改构图 | 按选区、时间或素材定位对象，编辑并同窗复看；实质歧义才提问 | 修改落在所选对象，其他轨道和声音保持 |
| 要求成片 | 展示实际报价，按授权导出，审阅确切 MP4，说明未满足之处 | 可播放、下载的固定 Output 和相应账本 |
| 中途停止或回来继续 | Stop 对应原 opening；刷新后读取真实版本与执行回执 | 已保存的修改可用，旧交付不漂移，无重复写入和扣费 |

当前首片、跨素材盲测及费用要求见 [I8](tasks/i8.md)。历史首错与复测分别见 [I6](tasks/agent-editor-evidence/iteration-6/final-closure.md) 和 [I7](tasks/agent-editor-evidence/iteration-7/README.md)。
