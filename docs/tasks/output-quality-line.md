## 0. Context

用户的判词（2026-08-22）："图文视频把图片轮播放几个字，这样的产物配不上用户花钱。这不是虚拟生成，需要非常惊喜的细节把控。我们目前不够，因为可能存在架构问题。"

读码 + 两轮外部评审后的归因：**是架构问题，但是"缺层缺环"，不是推翻**。

- **缺一层**：storyboard（说什么）与 clip-spec（怎么渲）之间没有"timeline 创作"层——逐拍决定（哪张图停多久、何时切、强调哪个词）没有 owner，现由配方默认值 + 阅读速度常量代劳（`tools/stills/procedure.py`：zh 4.5 字/s、句间 0.35s 的节拍器）。这是"轮播+浮字"味道的来源。
- **缺一环**：产物出来后没有任何质检回看，质量没有地板也没有改进回路。
- **缺一把尺**：没有任何质量度量——不知道差在哪、差多少、改没改好。

不动的东西（两轮外部评审三源背书 + 常备否决不翻案）：DAG 编排、模型永不直调工具、图是唯一调用方、clip-spec 契约（ADR-016）、表面纪律（ADR-041）、意图单面。**全部是加层加环，零推翻。**

## 2. 设计

### 2.1 craft 语法 v0（先验表——剪辑师与质检环共用这一份）

三源评审收敛的编辑部惯例。**用法**：① 转写为剪辑工艺指令包（SKILL.md，装配期注入剪辑师）② 可测量项转写为质检环的确定性检查。标注：数值 = 先验，解剖校准。

**talking-head clips（真素材剪切）**：

| 规则 | 可测量条件（先验） | 缺失症状 |
|---|---|---|
| 钩子延迟 | 首个发声 ≤300ms；无 lead-in 静音/filler | 即划走 |
| 钩子有料 | 开场 = 全片信息密度最高句（非时间序首句） | 像讲座开场白 |
| 思维边界切 | 切点落句/从句边界 ±180ms；**静音只是必要非充分**（从句中间的停顿不可切）；前垫 100–150ms、尾垫 150–200ms | 机器人跳剪/丢 momentum |
| filler/死寂清除 | >600–800ms 停顿与 um/uh 类 filler 移除（有意节拍除外） | 像生肉素材 |
| 强调跟韵律 | 强调（缩放/字幕炸出）对齐音高/能量峰，非"看起来重要"的词 | 特效随机乱贴 |
| 字幕节奏 | 卡拉 OK  burst 1–3 词/组、200–800ms/组、±30ms 同步；或短语式 ≤2 行 32–42 字符/行（风格二选一是皮肤层决定） | 字幕墙/跟读滞后 |
| 切频包络 | 无 >2 连切 <1s；无静态镜头 >8–10s | 焦虑或死寂 |
| 收束 | payoff 落最后 15–20%；末句完整陈述或明确开放环；尾帧停 ≥1.8s | "就这么没了" |
| 眼位/脸宽 | 9:16 眼位 35–45% 高、脸宽 30–50%（reframe 验收数字） | 淹没/切头/字幕盖脸 |

**图文视频（照片+文字稿）**：

| 规则 | 可测量条件（先验） | 缺失症状 |
|---|---|---|
| 视觉钩子匹配 | 首图 ≤0.6s 出现且主体对应首个强调短语 | 声画两张皮 |
| 图停甜区 | 均停 2.4–4.8s；强调词处 1.6–2.4s；永不 <1.3s / >4s | 幻灯片 boredom / 频闪 |
| 运动带原因 | Ken Burns 缩放率 1.05–1.20×/段；**相邻图交替方向**；ease 200–300ms 不贴切帧 | 静态轮播/晕动 |
| 切在意义上 | 图切换落从句边界/强调词 ±200ms，永不落词中 | 声画互搏 |
| 强调隔离 | ≥60% 强调词获得 hold/推近/字幕炸出其一 | 平铺无指向 |
| 结构呼吸 | 每 12–18s 一次"复位"（更宽构图/更慢运动/短停） | 无休止感 |
| 音频闪避 | BGM 对人声 -18~-22dB；>800ms 停顿回升 -12dB；人声 -14 LUFS ±1（与现有响度规范一致） | 音乐盖人/死寂 |

### 2.2 理解层 v2（节拍地图）

`MaterialUnderstanding` 扩展为素材级节拍地图（与需求池「素材理解前移」汇合：上传时跑、asset-hash 复用、asset 级持久化）。新增字段：

| 字段 | 生产者 | 错了/缺了下游断什么 |
|---|---|---|
| `topic_boundaries` | LLM 语义分段，锚定 ASR 句末时间戳 | 切点跨话题、图序乱 |
| `climax_spans` | **LLM 语义读 + 声学能量/音高变异分开存**（Claude 金矿：两信号不一致本身是剪辑师仲裁信息，预合并 = 自信地错且不可溯源） | 钩子/收束无料可选，退化为时间序首句 |
| `emphasis_words` | 确定性 prosody 工序（pitch F0 z-score/能量峰，新 asset processor，ASR/speaker_map 同族）+ LLM 语义权重——**两个字段，不合并** | 强调落在"而且/因为"上 |
| `quotable_lines` | LLM 抽取 + **自包含检查**（无悬垂代词） | 金句卡/字幕拉出不完整句 |
| `visual_anchors` | 确定性 vision（人脸/主体/安全区）+ 轻 LLM 语义匹配 | 图文声画错位、运动切脸 |
| `filler_regions` | 确定性（词表+停顿时长阈） | filler 保留 = 业余感 |
| `narrative_role_hints` | 单次 LLM 全稿 pass（setup/payoff/example/transition） | 节奏纯局部贪心，无全局弧 |

**铁律两条（三家收敛）**：① 词级时间戳 = 确定性地基，**LLM 永不覆写**；② 语义/声学强调**分字段存储**，禁止预合并为单一分。

### 2.3 剪辑师 editor（团队下一成员，N-30 声明）

新 Agent 声明（首接 stills 图文视频包——用户点名的痛点；clips 包后续接）。输入 = 理解层节拍地图 + 词级时间戳 + 视觉元数据；产出 = **beat plan（节拍方案）**——逐拍决定图序/运动/切点/强调，作为 clip-spec 编译的丰富输入。

**上限纪律（三源收敛）**：单发可靠域 **≤8–15 拍 / 30–45s**。超出走两段：

1. **大纲段**：全局叙事弧 + 资源约束（已用图清单、高潮分配）；
2. **逐拍段**：每拍携带**显式交接状态**——时间锚点（span_id + [start,end]）、上一拍出点视觉态（last_motion/pacing_density）、累积强调词历史、节奏曲线目标位置。防漏点全在拍间：全局意图、素材占用（一图只用一次）、强调去重。

**跨拍连贯性检查独立存在**（节奏曲线/强调多样性——机械质检查不出这类退化）。

### 2.4 质检环 v2（吸收旧简报期 3 并升级）

旧简报已定稿的保留：verify = 节点 kind、QualityBounce 打回传输、attempt ≤2、executor 幂等重跑、成本落 executor 节点、不进 TOOL_REGISTRY、前端只加 kind i18n。本简报升级六条：

1. **确定性优先**：可测量项（钩子延迟/图停/字幕同步/人脸安全区/响度）代码验，零 LLM；模型评审只管主观项（强调词贴不贴内容、金句上下文可读性）。
2. **逐轮独立打分 + best-not-last**：每轮候选独立评分，末轮更差回退首轮（三源全体独立点名——循环非单调，"最后一轮 ≠ 最好一轮"）。
3. **字段白名单最小 diff 修复**：修复只许动被标记字段（防重写整条时间轴 + 为局部重渲留可能）。
4. **首轮通过即跳轮**（固定两轮引入无谓回归风险）。
5. **双败升级 interrupt**（复用现有 interrupt 机制，S36–S40 有锁）。与旧简报 `needs_human` 徽章的关系：**fidelity 类（保真/逐字/语言）维持 needs_human 非阻塞徽章；craft 类（钩子/节奏/强调）双败给 interrupt 选项**——用户可降级接受（产物照常落地，徽章同现）。
6. **失败路由判据（机械可执行）**：修复所需信息不在理解层 schema 里、或超出单节点参数域 → 升级重规划边（交还意图层，汇合需求池 P1「执行中自适应重规划」）；参数域内 → 节点内修。**retry 不中自动升级**（schema 错误首 pass 常伪装成参数错误）。素材级不足（无高潮/图耗尽/能量平）→ 诚实降级路径：interrupt 提供「标题卡开场 / 换素材」选项——**不假造钩子**（顾问姿态四律：带理由纠偏）。

### 2.5 钩子预览闸（产品面新闸）

**论证**：craft 规则里钩子延迟/节奏/强调/收束四条**静态形态验不了**（文本分镜与首帧对时序全盲），而钩子是后果最重的段——把唯一一次付费预渲染花在它身上。全预览每变体都给 → 评审疲劳、盖章通过。

- **渲染服务新能力**：局部低清渲染（clip-spec 前缀子集 + 低清低码率参数，秒级出；黑盒内部消化，ADR-016 契约不破）。
- **UX**：缩略图序列（查结构：图序/文案/节拍标签，扫读快于文本列表）+ 前 3–5 秒钩子低清预览（查节奏）+ 轻量调整口（换图锚/调尾切点）。**用户时间预算 ≤15 秒**——精致在产物里，不在对话里。
- **时机**：全量渲染前。位置 = 确认 dock 家族（一面一 MentionEditor / 现有 dock 体系延伸，不新造表面）。

### 2.6 台账三信号（汇合需求池 P1「agent 调用台账」）

台账的表设计与落库归该池项（DeepSeek 评审血脉）；本简报供给质量信号 schema：

1. **过程信号**：repair 轮次 + 修复 diff 幅度（模型挣扎的领先指标）。
2. **机制信号**：质检违规类型分布（区分系统性漂移与随机噪声；pass/fail 汇总量看不出来）。
3. **地基真值信号**：用户事后 edit-ops **按节点归因**（ undo/微调率聚集的节点 = 欠交付节点——"像不像人剪的"的最终裁判）。

### 2.7 judge rubric 纪律（引入 LLM 评审的约束——旧简报"单独评审"的兑现）

- 确定性/模型判**分离**；模型判只做主观项。
- **pairwise 对冻结基线**，不打绝对分（分随系统改进漂移压缩）。
- **具体样例锚定**（自家语料的好/坏实例），禁抽象 1–5 分（向中间压缩）。
- **证据引文先行**（先指时间戳/元素，后给判词）；子问题分解先于整体判断（防光环效应）。
- 位置随机化消偏差；judge 对 provenance 盲；温度 0 + 结构化输出。
- **模型/提示词任何变更必跑人类校准集**（judge 漂移无地面真值不可检测）。
- 判 debug 路由：确定性全绿而 judge 挂 → 优先查理解层 schema 字段，不是剪辑师。

### 2.8 解剖流程（尺子先行）

每张 live 配方卡 × 真素材（`demo/uploads/` 策展集 + xy_1/xy_2）：

1. 出产物 → 按 §2.1 清单逐条打分（可测量项脚本化；主观项人工判）。
2. 每个 gap 归因四层：**数据 / 决策者 / 契约 / 渲染**。
3. 产出 = 证据表（差距量化 + 归因 + 先验阈值校准值）。
4. 判片纪律：帧目录按 take 隔离 + md5 对齐 URL stem（防串台误判）。

解剖输出决定期 2/期 3 的施工顺序——**没有尺子不砍树**。

## 6. 禁止行为（Prohibited Behaviors）

1. **禁**推翻 DAG / 引入模型驱动编排（三源外部背书 + 常备否决）；**禁** tool-loop/steering 翻案——节点内有界环是唯一合法循环形态（ADR-047）。
2. **禁** LLM 覆写词级时间戳；**禁**语义/声学强调合并为单一分。
3. **禁**把 §2.1 先验阈值当验收标准——解剖校准前它们只是默认值。
4. **禁**静态闸验钩子（文本分镜/首帧对节奏全盲）——钩子必须真渲染预览。
5. **禁**全量重渲当修复——修复 = 字段白名单最小 diff；局部重渲能力评估归渲染服务。
6. **禁**"最后一轮即最终"——质检环必须逐轮独立打分、best-not-last。
7. **禁**抽象分 judge（无样例锚定的 1–5 分）；**禁** judge 知道 provenance。
8. **禁**多角色署名到用户面（N-25 不破）；场景化助手 = 同一个"它" + 作用域上下文（ViewScope 归后续简报）。
9. **禁**运行时 skill discovery——剪辑工艺包走既有装配期注入（N-42 ⑦ 纪律不变）。
10. **禁**质检阻塞 run——craft 双败 = interrupt 可降级接受；fidelity 维持 needs_human 非阻塞徽章。
11. **禁**用户加节点 / 多轨时间线编辑器（ADR-035/041 与 L3 委托纪律不翻）；分镜显形若做 = 系统产物显形，与用户加节点无关。
12. **禁**无解剖先动期 2/期 3——尺子先行。
