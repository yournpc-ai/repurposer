## 实现与回归范围

- `PlanTurn.finish` 在重复拒绝、预算用尽或终止性拒绝时，锁定并刷新原 opening。`_committed_edits` 核对 request、owner、project 和不可变版本。`partial_edit_text` 读取对应修改、当前 head、授权／Job 回执与既有交付的 Output 和审阅身份。普通结束只写一次消息。
- 实际异常沿 `settle_failed_chat_turn` 结算。恢复与普通结束共用事实读取，Activity 修复仍由中断入口负责。流式出口和 Web 错误行沿用持久 ID，JSON 的供应商失败保留 502。
- PostgreSQL 定向回归 44 项通过，覆盖已有编辑、交付、Stop 与导出竞争，以及新增五个异常收尾用例。新增用例包括独立写入导致的旧 opening、并发推进 head、待授权、历史先恢复、同一调用重放。另跑 Activity 回归 14 项通过。Web 帧与消息身份回归 46 项通过，Web TypeScript 检查通过。
- 预算耗尽与终止性拒绝由确定性用例覆盖。真实供应商修后再次命中相同部分失败、生产环境、多浏览器竞争和所有媒体供应商的在途状态均未验证。本轮结论仅覆盖 P0，普通 Finish 设计仍待 P1 审批。
