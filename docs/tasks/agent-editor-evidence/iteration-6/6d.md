## 新素材、首次交付与续改实测

在隔离账户新建项目，经 HTTP 上传 6 秒的公开授权合成动画。用户用 Chat 要求制作约 5 秒短片并添加旁白与配乐。首次 opening 确实失败，API 日志记录磁盘写入 ENOSPC。失败前两项 MediaJob 已完成，各领取一次，初稿版本 1 已保存。仅清除本次临时目录内与工作区逐字节相同的副本，释放约 197 MB。用户再次要求从原稿继续后，模型读取时间线，发现配乐尚未插入，复用已有素材插入，生成版本 2 并观看真实预览。

用户明确导出第 2 版，随后要求放大光球。模型在同一作品修改缩放，保存第 3 版，再次预览。在用户正式授权后，两版均经 export_video、独立 Worker、Renderer、TOS、review_video 和 deliver_video 交付。测试仅按确切版本放行合成素材使用公开桶。旁白实际结算 3 积分，配乐 0，两次导出各 10，隔离账户从 1,000 到 977。两项 MediaJob、两项 ExportJob 的 attempt 均为 1。真实 MiniMax 请求和领域回执见 [新素材实测](6d-native-journey.json)。

Chrome 在项目页分别打开两个固定 Output，硬刷新后重开原卡并播放。通过每次播放器实际取得的 URL 下载 MP4，校验数据库中的 SHA-256 和每版 150 帧。两版均为 1920×1080，内容摘要不同。此次验证有一次用户主动恢复，不能计作首次请求不间断完成。它未覆盖十用户同时负载。
