## 2. 叙事机制（综合观察）

1. **Hero 标题 = 轮播任务，不是价值主张。** 品类句（"你的 AI 设计助手"）恒定承担定向，标题槽位让给用户具体的活儿；价值靠场景自明。
2. **每幕 = 一个能力 = 输入 → prompt → 输出，滚动驱动。** prompt 条/泡随滚动浮入、结果随滚动级联——滚动本身在演示"生成"，全程零交互要求（无 hover、无点击、无拖拽）。
3. **prompt 永远可见，且是用户原声**（口语、具体、可照说）。prompt 是证据的一部分：同时证明交互模型（你只要说话）与教提示词素养。
4. **过程折叠进截图，无 How-it-works 幕**——agent 步骤（已分析/已探索/已收集）在 hero 产品截图内自陈。
5. **身份资产与工具能力平级成幕**（幕 4 风格一致性），且用实物对照证明（同一风格跨版本/格式在线），非形容词声称。
6. **每幕 CTA 深链进能力**（体验点选编辑/探索风格一致性）——证据即入口。
7. **零商务尾**：定价在导航不在页；无 FAQ、无宣言、无背书。整页 = hero 轮播 + 3 个 demo + 终幕 CTA + 页脚。
8. **幕文案纪律**：meta 小标 + 标题 ≤10 字 + 正文 ≤3 行；证据承载全部分量。
9. **单助手叙事**：内部多 agent/多模型，用户面恒定"你的 AI 设计助手"单数一个。
