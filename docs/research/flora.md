## 1. 产品模型事实

- 定位：节点画布（node canvas）创意工具，目标用户 = 专业创意团队（时尚/VFX/广告/品牌）。
- 聚合 50+ 第三方模型（Google Nano Banana/Veo、Runway、OpenAI、Luma、BFL、Wan、Kling、Seedream、Higgsfield…），卖点 "One subscription to rule them all"。
- 内置助手名 FAUNA（dock 常驻免责行："FAUNA is AI and can make mistakes. Check important info."）。
- 定价（季付截图）：Free / Starter $14.40 / Pro $40 / Max $160 per seat/mo；Enterprise 单独 tab。Free 含 1 seat、3 projects、图/音/文模型（视频模型无）、FAUNA unlimited。
- 核心概念：Canvas（无限画布）/ Nodes（Text/Image/Video/Audio/Upload 块）/ Techniques（可复用工作流，官方 + 创作者署名）/ Flows（行业工作流）。

## 3. Technique → Canvas 交互走查

- 配方卡 hover：两个动作——Try（弹窗）/ Open（直接进项目画布）。
- Try 弹窗：左列 = 输入表单（每输入一个上传框 + Use preset）+ 时长（~2 min）+ Generate；顶部 App/Workflow 切换；Workflow tab = 只读 flow，**用大圆角区域框（group frame）把中间节点组包起来并标注配方名**表示"大叙事"；底栏 "You're viewing a read-only Technique workflow. [Open in Project]"。
- Open：logo loading → 全屏画布。布局：左上 project 菜单（Back to home / New / Duplicate / Rename / Undo ⌘Z / Redo / Project settings）；右上 缩放% + Build Technique + Share Project；左侧垂直工具栏（添加/文件/人物/#/历史/框选/搜索/评论/?/头像）；左下 积分（"100% Left | Upgrade now"）；中央画布自适应居中；首次出现 tour（Comments 教学卡）。
- Chat：默认收在右下角动态点阵 icon；点开为浮窗（welcome "Good evening, 晏铭." + 四条快捷指令 + placeholder "Use '@' to mention nodes and '/' to use skills"）；可 dock 成右侧固定栏（Undock panel ⌘\，画布布局让位）；长聊有 "Jump to latest" 浮 pill；dock 常驻 FAUNA 免责行。
- 节点：hover 出 toolbar（Tools/图像/圆/方/箭头/下载/放大）；点击节点 → 右上按顺序挂悬浮信息窗（Format/Size/Resolution/Created/Creator + 一行编辑图标）。
- 头像与 Upgrade 开同一个账号 modal 的不同 item（Profile / Preferences / Integrations / Settings / People & Seats / Plans & Billing）。
