## 2. 调用边界与机制

原调用为固定版本 → compile_video_spec → 正式 renderVideo → renderMedia → 合并 WAV → libfdk_aac/ADTS → 音频 copy 到 MP4 → 两遍 loudnorm 或跳过/回退。第一个错误见于 ADTS 丢失起始负时间和 skip 标记。

候选保留版本编译、共享 Video、Sequence 和 Remotion 混音。公开 audioCodec=pcm-16 与 H.264/MOV 在锁定的 4.0.484 上实际可用。独立探针解码得到 1,536,000 字节双声道 PCM16，与原合并 WAV 的 PCM 数据逐字节相同。候选将该 MOV 的 H.264 包复制到 MP4，在同一次封装中编码 AAC，原样调用现有 loudnorm。无新增包、全局 FFmpeg 替换、手写混音、固定时间补偿或第二套 Renderer。探针与故障注入均在临时实验进程内。
